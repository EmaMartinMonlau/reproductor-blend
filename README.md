Blend - Reproductor Musical 🎵

¡Hola! Este es "Blend", un reproductor de música web personalizado que he creado como proyecto práctico.

El objetivo principal era construir una interfaz funcional y atractiva desde cero. Cuenta con todas las opciones clásicas de un reproductor: puedes pausar, darle al play, saltar entre canciones de la lista, ajustar el volumen y arrastrar la barra de tiempo. Como extra, le he programado un ecualizador y un visualizador de barras animadas que bailan en tiempo real al ritmo de la música que esté sonando.

Toda la lógica profunda del código y cómo funciona por detrás está explicada paso a paso en el PDF de documentación que también he subido a esta carpeta.

------------------------------------------
¡Muy importante para ejecutar el proyecto!
------------------------------------------

Para que el reproductor funcione y la lista de canciones cargue correctamente, es obligatorio abrir el proyecto utilizando un servidor local.

Si usas Visual Studio Code, te recomiendo usar la extensión Live Server. Solo tienes que hacer clic derecho sobre el archivo index.html y seleccionar la opción "Open with Live Server".

(Si intentas abrir el archivo index.html directamente con doble clic en tu navegador, este bloqueará la carga de las canciones por políticas de seguridad y la pantalla se quedará vacía).
